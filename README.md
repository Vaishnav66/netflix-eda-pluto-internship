# Netflix Movies & TV Shows – Exploratory Data Analysis

## About the Project

This project was completed as part of the Pluto AI & Machine Learning Internship.

The project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset to understand patterns in Netflix content.

## What Was Done

- Loaded and inspected the Netflix dataset
- Checked data types, missing values, and duplicate records
- Cleaned missing and inconsistent values
- Analyzed Movies and TV Shows
- Studied title distribution across release years
- Analyzed countries contributing Netflix titles
- Identified common genres
- Analyzed movie duration
- Created multiple data visualizations
- Extracted key findings from the analysis

## Visualizations

The project includes:

- Bar Chart
- Line Chart
- Histogram
- Pie Chart
- Scatter Plot
- Correlation Heatmap

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
